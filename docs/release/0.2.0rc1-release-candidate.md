## Scope

This candidate contains:

- canonical Hermes Project/Kanban host contract v2;
- native project/board onboarding with idempotency and recovery;
- canonical Board, Backlog table and work-item details;
- Board/Table Saved Views with Timeline explicitly unavailable;
- manually started, versioned workflow DAGs with human gates and run journal;
- marker-guarded legacy work migration with snapshot rollback;
- operational Dockyard database export and isolated restore;
- responsive Desktop/plugin surfaces, approvals, notifications and fleet views.

## Canonical authority

- Hermes Projects/Kanban owns projects, boards, tasks, epics, hierarchy,
  dependencies and execution state.
- Dockyard owns policy, evidence, rankings, views, workflow definitions/runs,
  approvals, reports and audit metadata.
- Production work writes use the host adapter. No legacy task dual write is
  permitted.

## Security and lifecycle

- Host failures are redacted and fail closed.
- Dashboard source/dist prohibit unsafe DOM/script/storage sinks.
- Workflow definitions validate IDs, dependencies and cycles before writes.
- Workflow runs reserve a pending journal before canonical writes and recover
  through deterministic node keys.
- Legacy migration accepts only marker-owned isolated roots.
- Operational restore rejects traversal, symlinks, existing targets, checksum,
  size, integrity and schema mismatches.

## Known limitations

- Current Saved View UI applies Board/Table layout, not the full role-aware
  filter/query roadmap.
- Timeline remains unavailable until canonical scheduling semantics exist.
- Workflows are manual only; no scheduler is activated.
- Levels 4-5 remain disabled pending the merge-gate roadmap decision.
- Broader product work remains in [`../../roadmap.md`](../../roadmap.md) and is
  prioritised in [`../DOCKYARD-NEXT-PLAN.md`](../DOCKYARD-NEXT-PLAN.md).
